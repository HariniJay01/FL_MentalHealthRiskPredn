ℹ️ About This System
🔒 Privacy-First Design
Raw social media posts never leave the client node. Only model weights (gradients) are transmitted to the aggregation server.
⚡ FedAvg Algorithm
Each round, client weights are aggregated via weighted averaging proportional to local dataset size.
🧠 Model Architecture
HashingVectorizer (n=65536, bigrams) + SGD Classifier (log-loss). Supports incremental learning and federated weight sharing.
📊 Mental Health Mapping
Sentiment 0 (negative) → At Risk. Sentiment 4 (positive) → Safe. Risk probability calibrated via Platt scaling.

Client Nodes

Each node represents a social media platform. Upload data and train locally — data never leaves the node.

📚 Metric Definitions
Accuracy
Fraction of posts correctly classified (risk vs safe).
F1 Score
Harmonic mean of Precision and Recall. Robust to class imbalance.
Precision
Of all posts flagged as "at risk", how many truly are?
Recall
Of all truly "at risk" posts, how many were detected?
AUC-ROC
Area under ROC curve. 0.5 = random, 1.0 = perfect classifier.
Risk Ratio
Fraction of the platform's posts classified as mental health risk.
Log Loss
Measures calibration quality of predicted probabilities.
Weight Divergence
Std dev of L2-norms across client models. Lower = better convergence.

💡 How It Works
1️⃣ Text is pre-processed (normalised, URLs removed)
2️⃣ HashingVectorizer converts to bigram feature vector (65K dims)
3️⃣ SGD Classifier predicts risk probability
4️⃣ Global weights from latest FedAvg round are used
5️⃣ Results shown with confidence score per text
